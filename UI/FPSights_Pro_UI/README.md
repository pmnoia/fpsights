# FPSights Professional Gaming UI

Responsive Valorant-inspired PySide6 UI prototype for the FPSights senior project.

## Run
```bash
cd ~/SP_1
unzip FPSights_Pro_UI.zip
cd FPSights_Pro_UI
python3 fpsights_pro_ui.py
```

If PySide6 is missing:
```bash
pip3 install PySide6
```

## Included Pages
- Dashboard
- Analyze VOD
- Report
- Heatmap
- Compare
- Settings
